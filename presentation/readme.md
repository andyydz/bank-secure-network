# Project Presentation

This folder contains the presentation prepared for the **Bank Secure Network** academic project.

## Presentation

`Bank-Secure-Network.pptx`

The presentation provides a summarized overview of:

- Problem Statement
- Project Objectives
- Network Architecture
- Network Topology
- VLAN Segmentation
- IP Addressing
- Network Services
- Security Implementation
- ACL Configuration
- Testing
- Benefits and Use Cases
- Conclusion

## Purpose

The presentation was created to explain the design, implementation, security features, and practical applications of the simulated banking network.

The detailed technical implementation is available in the [`documentation`](../documentation/) folder.

The actual Cisco Packet Tracer project is available in the [`packet-tracer`](../packet-tracer/) folder.
